# seat-planner（社内限定）

コンサルティング事業部の組織編成ボードと、けんびや提案メール送信マニュアル。
GitHub Pages で公開しているが、**合言葉を知っている人だけ**が中身を見られる。

## 仕組み

ページ本体は AES-256-GCM で暗号化した状態でコミットしている。
ブラウザで合言葉を入力すると、その場で復号してページが表示される。
リポジトリのソースを見ても中身は読めない。

- `src/*.html` … 編集する平文（**コミットされない**）
- `*.html` … 公開される暗号化済みファイル（自動生成、直接編集しない）
- `gate.template.html` … 合言葉入力画面のテンプレート
- `build.mjs` … 暗号化ビルド

## 更新のしかた

`src/` の中を編集してから、以下を実行して push する。

```bash
PASSPHRASE='合言葉' node build.mjs
git add -A && git commit -m "update" && git push
```

合言葉を変えたいときは `PASSPHRASE` に新しい合言葉を入れてビルドし直すだけ。

## 注意

- `src/` はこのリポジトリに入らないため、平文はローカルにしか無い。バックアップを取っておくこと。
- 合言葉はリポジトリにも Pages にも一切書かれていない。口頭や社内チャットで共有する。
